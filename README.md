# FastAPI Learning Roadmap

Lộ trình học từ **zero → production-ready backend** với Python + FastAPI + PostgreSQL.

## Triết lý học

> **Học bằng cách build.** Mỗi phase đều kết thúc bằng một mini-project thực tế. Không chỉ đọc docs.

## Cấu trúc roadmap

```
fastapi-learning/
├── phase-0-python-basics/       # 1 tuần - Python nền tảng
├── phase-1-python-advanced/     # 1 tuần - Type hints, async, OOP
├── phase-2-fastapi-basics/      # 1 tuần - FastAPI core, Pydantic
├── phase-3-database/            # 1-2 tuần - PostgreSQL + SQLAlchemy async
├── phase-4-auth-security/       # 1 tuần - JWT, OAuth2, permissions
├── phase-5-testing/             # 1 tuần - pytest, httpx, TDD
├── phase-6-production-project/  # 2-3 tuần - App hoàn chỉnh (Blog API)
└── resources/                   # Cheatsheets, snippets, debugging tips
```

## Thời gian tổng

- **Tối thiểu:** 8 tuần (2 giờ/ngày)
- **Thoải mái:** 12 tuần (1 giờ/ngày)
- **Bootcamp mode:** 4 tuần (6+ giờ/ngày)

## Cách dùng roadmap này

1. Đọc `PHASE.md` của từng phase → hiểu mục tiêu
2. Làm theo `exercises/` → gõ tay, không copy-paste
3. Hoàn thành `mini-project/` → đó là "bằng chứng" bạn đã hiểu
4. Kiểm tra bằng `checklist.md` trước khi sang phase tiếp

## Quy tắc vàng

- ✅ **Gõ tay code** - đừng copy
- ✅ **Lỗi = bạn tốt** - đọc traceback, đừng panic
- ✅ **Commit thường xuyên** - mỗi exercise một commit
- ✅ **Nghỉ khi stuck > 30 phút** - đi bộ, quay lại với góc nhìn mới
- ❌ **Đừng học tất cả cùng lúc** - tuân theo thứ tự phase
